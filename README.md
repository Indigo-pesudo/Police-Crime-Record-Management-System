# Police Crime Record Management System (PCRMS)

## Overview
Police Crime Record Management System is a Java Swing desktop application developed to digitize police record management.

## Features

- Role Based Login
- Administrator Dashboard
- Inspector Dashboard
- Record Clerk Dashboard
- Logout
- Professional Java Swing UI

## Technologies

- Java
- Swing
- AWT

## Modules

- Login
- Dashboard
- User Management (Upcoming)
- Register FIR (Upcoming)
- Evidence Management (Upcoming)
- Case Management (Upcoming)
- Criminal Records (Upcoming)
- Reports (Upcoming)
